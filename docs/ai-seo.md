# AI-SEO: видимость в ответах нейросетей

Админка → «Сводка» → «SEO» → «AI-SEO» (`/admin/seo/ai/`). Устроено так же,
как раздел AI-SEO в prime-auto. Код — `src/lib/ai-seo.ts`, общее для
админки и сборщика — `src/lib/ai-seo-shared.mjs`, сборщик логов —
`scripts/ai-seo-collect.mjs`. План работ — `SEO-PLAN.md`, раздел AEO / GEO.

## Слои

1. **Ответы нейросетей** — главный показатель. Набор из 25 запросов
   (`AI_QUERIES`): стёкла, световоды, рамки, би-LED, магазин и бренд. По
   каждому: назван ли vdf.by, есть ли ссылка и каким по счёту источником,
   на кого ссылаются вместо нас.
   - Perplexity, ChatGPT и Gemini — автоматически, кнопкой «Проверить
     ответы нейросетей». Запросы идут через OpenRouter с тем же ключом и
     прокси, что генерация текстов (`AI_API_KEY`, `AI_PROXY`): модель +
     поиск в интернете (`plugins: web`). Это близко к ответу обычному
     человеку, но не то же, что приложение: у приложений своя память и
     настройки. 75 запросов по 4 одновременно, 1–3 минуты, около $1.
     Расходы видны в «Нейросеть для текста» с задачей «AI-SEO».
   - У Gemini рассуждение не отключается («Reasoning is mandatory»), поэтому
     у него `reasoning: { effort: "low" }`; поле `extra` в запросе
     применяется последним и перекрывает общие настройки OpenRouter.
   - Источники Gemini приходят переадресацией Google
     (`vertexaisearch.cloud.google.com/grounding-api-redirect/…`) —
     раскрываются в настоящие адреса.
   - «VDF-light» (vdf-light.ru, сторонний сайт) упоминанием vdf.by не
     считается.
   - Яндекс Нейро, Алиса и Google AI Overviews API не дают — отмечаются руками
     в форме на той же странице, раз в месяц, в инкогнито.
2. **Переходы из нейросетей** — Яндекс.Метрика, последние 12 месяцев, живой
   запрос с кешем на 10 минут (своего счётчика у магазина нет). Визит
   считается переходом из нейросети, если «Источник трафика (детально)» или
   `utm_source` — chatgpt.com, perplexity.ai, gemini.google.com, copilot,
   claude.ai, deepseek, alice.yandex.ru и др. (`AI_REFERRER`,
   `AI_SOURCE_NAME`). Цели — `order`, `fit_check`, `product_messenger`.
   Переходы из Яндекс Нейро приходят с ya.ru и от поиска не отличаются.
3. **ИИ-боты по логам nginx** — `scripts/ai-seo-collect.mjs`, cron
   `/etc/cron.d/vdf-ai-seo` в 7:10, лог — `var/ai-seo.log`. Читает
   `/var/log/nginx/vdf.by.access.log*` (в контейнер `tools` смонтирован
   только на чтение), пишет `ai_bot_hits` по дням, ботам и страницам.
   Бот засчитывается, только если IP из его официального списка (OpenAI,
   Perplexity, Google, Bing), а где списка нет — если с этого IP не было
   сканирования (`.env`, `.git`, `wp-` и т. п.): под ИИ-ботов массово
   маскируются сканеры уязвимостей. Каждый полный день пересчитывается
   целиком, запуск можно повторять; сегодняшний день не пишется.
   - `answer` — страницу открыли во время ответа человеку (ChatGPT-User,
     Perplexity-User, Claude-User) — самый ценный сигнал;
   - `search` — индексация для поиска внутри нейросети;
   - `train` — сбор для обучения.
4. **Вопросные запросы** — из снимков сводки SEO (`seo_snapshots`):
   «как / почему / сколько / можно ли…» и запросы от пяти слов без
   коммерческих слов и бренда. Считаются при открытии страницы для новых
   снимков и хранятся в `ai_questions` дольше самих снимков. Если показы
   растут, а CTR в топ-5 падает — ответ забирает нейроответ поиска.

Внизу страницы — чек-лист готовности сайта (`READINESS` в
`src/lib/ai-seo.ts`), статусы правятся в коде по мере выполнения.

## Запуск вручную

```
docker compose run --rm --no-deps tools node scripts/ai-seo-collect.mjs
```

Локально: `NGINX_LOG_DIR=папка-с-логами node scripts/ai-seo-collect.mjs`.
