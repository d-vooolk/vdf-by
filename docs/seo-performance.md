# Скорость и SEO: что настроено и что сделать руками

Итог аудита от 2026-09-27: обход всех 4362 адресов sitemap, Lighthouse по
типовым страницам, разбор кода. Здесь — что изменено и какие шаги на сервере
деплой не делает сам.

## Шаги на сервере (один раз)

Деплой копирует код, но не конфиги nginx и PM2.

1. **nginx.** Скопировать `deploy/nginx.conf`, как описано в
   `docs/rate-limit.md` («Как применить на сервере»). Конфиг подключает
   `deploy/nginx-headers.conf` прямо из папки сайта — общие заголовки
   безопасности теперь в одном файле и не теряются в `location` с
   собственным `add_header`. Проверка: `nginx -t && systemctl reload nginx`.
2. **HTTP/2.** Сейчас сайт отвечает по HTTP/1.1. Включается на общем
   `listen 443`, то есть сразу для всех сайтов этого сервера, поэтому в
   конфиг не внесено. На nginx 1.24 — дописать `http2` в обе строки
   `listen … 443 ssl` блока vdf.by (`listen 443 ssl http2;`). На 1.25.1+ —
   `http2 on;` внутри `server`. Для остальных сайтов на этом IP это тоже
   включит HTTP/2; обычно это только плюс, но решать владельцу сервера.
3. **brotli (по желанию, −30% к весу HTML и CSS).**
   `apt install libnginx-mod-http-brotli-filter libnginx-mod-http-brotli-static`,
   затем `cp deploy/nginx-brotli.conf /etc/nginx/vdf-brotli.conf`.
   Конфиг подключает файл по маске `vdf-brotli*.conf`: пока файла нет,
   nginx работает без brotli и не падает.
4. **PM2.** В `ecosystem.config.cjs` появился `--keepAliveTimeout 75000`
   (Node не должен закрывать соединение раньше nginx). `pm2 reload` новые
   аргументы не подхватывает:
   `pm2 delete vdf && pm2 start ecosystem.config.cjs && pm2 save`.
5. **Порядок.** Сначала nginx (там `text/x-component` в `gzip_types`), потом
   деплой: Next больше не сжимает ответы сам (`compress: false`).

## Настройки магазина, которые влияют на разметку

- **Доставка.** В разметку товаров и в `feed.xml` попадает только доставка
  «По всей Беларуси» (новое поле «Куда возит» у способа доставки). На проде
  сейчас есть самовывоз и «Доставка по Минску» — значит, доставки в
  разметке не будет, пока не завести способ по стране (например «Почта по
  Беларуси», 1–3 дня). Порог «бесплатно от» учитывается по цене товара.
- **Дубли названий.** В «Незаполненных карточках» есть фильтр «название как
  у другого товара». Пока названия не различаются, в title автоматически
  дописывается артикул.
- **Вопросы-ответы.** Там же — кнопка массовой генерации нейросетью для
  товаров без блока «Вопросы и ответы». В форме раздела — рерайт описания и
  генерация FAQ раздела.

## Не сделано сознательно

- **Раздельный CSS витрины и админки.** Выигрыш ~1.5 КБ gzip, а стили
  админки зависят от темы и базовых классов витрины — риск поломать панель
  больше пользы.
- **ProductGroup для вариантов.** Google принимает `variesBy` только из
  короткого списка (цвет, размер, материал…), цоколь и сторона туда не
  входят. Оставлен набор Offer на каждую комбинацию.
- **Микрокеш nginx.** Не нужен: страницы каталога теперь статические.

## Как проверить после выкатки

```
npm run verify          в том числе новые проверки: alt, Clean-param,
                        дубли подбора, повторы title
curl -sI https://vdf.by/ | grep -i "cache-control\|x-powered"
curl -sI --http2 https://vdf.by/     (после включения HTTP/2)
```

В Яндекс.Вебмастере и Search Console: отправить sitemap заново, проверить
robots.txt, через пару недель — отчёт по дублям и «Страницы с
переадресацией/каноническими».
