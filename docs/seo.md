# SEO-сводка

Админка → «Сводка» → «SEO» (`/admin/seo/`).

## Откуда данные

| Источник | Что берём | Доступ |
|---|---|---|
| Google Search Console | клики, показы, CTR, позиции по запросам и страницам, по дням, sitemap | сервисный аккаунт, ключ `var/gsc-key.json`, ресурс `sc-domain:vdf.by`, права «Ограниченные» |
| Яндекс.Вебмастер | ИКС, страниц в поиске, диагностика, sitemap, популярные запросы, исключённые страницы | OAuth-токен `var/yandex-token.txt`, хост `https:vdf.by:443` (главное зеркало) |
| Яндекс.Метрика | источники, поисковые системы, входные страницы, цели, визиты по дням | тот же токен, права `metrika:read`, счётчик 112885899 |
| Сайты конкурентов | sitemap (размер, свежесть), главная (title, h1, разметка), ответ сервера, PageSpeed | открытые данные, без ключей |

Ключи лежат в `var/` на сервере, в git не попадают. Токен Яндекса живёт
около года — когда истечёт, сводка покажет ошибку 401, токен получают
заново тем же способом и кладут в тот же файл.

PageSpeed без ключа Google ограничивает по частоте. Если в таблице
конкурентов скорость пустая, задайте `PAGESPEED_API_KEY` в `.env`
(Google Cloud → APIs & Services → PageSpeed Insights API → ключ).

## Когда обновляется

`deploy/deploy.sh` пишет `/etc/cron.d/vdf-seo`:

- поиск и Метрика — каждый день в 6:20, `POST /api/cron/seo/?kind=search`;
- конкуренты — по понедельникам в 5:00, `POST /api/cron/seo/?kind=competitors`.

Кнопки «Обновить сейчас» и «Проверить конкурентов» запускают то же самое.
Снимки хранятся в таблице `seo_snapshots`: последних 120 по поиску и 60 по
конкурентам. Список конкурентов правится на той же странице.

Позиции сравниваются так: средняя позиция за последние 28 дней против 28
дней до них. У Google период сдвинут на 3 дня — Search Console отдаёт
данные с задержкой.

## Ключевые фразы и Topvisor

Вкладка «SEO → Ключевые фразы» (`/admin/seo/keywords/`). Список лежит в
файле `var/seo-keywords.json` на сервере: группы фраз, у каждой целевая
страница, приоритет, тип запроса и пояснение. У отдельной фразы может быть
своя страница — в редакторе это пишется как «фраза | /адрес/». «Скачать CSV
для Topvisor» отдаёт столбцы «Запрос; Группа; Целевая страница» — их
Topvisor принимает при импорте запросов из файла.

Рядом с каждой фразой — последние позиции из проекта Topvisor для vdf.by
по всем его регионам и отметка, отслеживается ли фраза. ⚑ — в выдаче стоит
не та страница, что задана целевой. Доступ — `var/topvisor.txt` (User ID и
API-ключ, по строке). Данные Topvisor кэшируются на 10 минут. Сайт только
читает Topvisor: запросы в проект не добавляет и проверки позиций не
запускает — они платные.

## Подборки в разделах

У раздела верхнего уровня могут быть подборки — отдельные страницы под
частые запросы: `/catalog/bi-led-moduli/linzy-3-0/`, `/catalog/bi-led-moduli/aozoom/`.
Задаются в админке в карточке раздела, блок «Подборки»: заголовок (H1),
подпись на кнопке, адрес, слова для отбора, тексты и SEO-поля. Товар
попадает в подборку, если хоть одно слово есть в его названии, бренде или
характеристиках; «3.0», «3,0» и «3″» сравниваются одинаково. Ссылки на
подборки стоят над товарами раздела, сами подборки — в sitemap. На
подразделах подборок нет: адрес вышел бы третьего уровня.

## Услуги и мастерская

Отдельных страниц услуг на vdf.by нет намеренно: услуги продвигает сайт
мастерской prime-auto.by. У сайтов общий адрес и телефон, и две похожие
страницы по одному запросу Яндекс может счесть аффилированными и показать
только одну. На /ustanovka/ — короткое описание работ со ссылками на
страницы мастерской и ориентировочные цены. Цены взяты из прайса
prime-auto.by/price и записаны в `PRICES` в
`src/app/(shop)/ustanovka/page.tsx` — при изменении прайса их нужно
обновить там же.

## Даты в sitemap

Дата страницы — время её последней правки в админке. Ночной пересчёт цен
по курсу дату не трогает: иначе каждую ночь больше тысячи страниц
объявлялись изменёнными, и поисковики переставали доверять датам.

## Отчёт в Markdown

```
node scripts/seo-report.mjs
```

На сервере — под Node 22 из nvm. Пишет `var/seo/report-ДАТА.md` и
`var/seo/raw-ДАТА.json` — удобно для подробного разбора.

## Чего здесь нет

Позиций конкурентов по запросам: Search Console и Вебмастер показывают
только свой сайт. Для этого нужен сервис проверки выдачи (Topvisor,
Yandex Search API) — подключается отдельным блоком.
