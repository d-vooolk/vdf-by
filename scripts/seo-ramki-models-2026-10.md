## kia/k5

Переходные рамки для Kia K5 рассчитаны на машины 2019–2024 годов с рефлекторными фарами — теми, где штатной линзы нет и ближний свет даёт отражатель. Рамка позволяет поставить в такую фару линзу и получить чёткую светотеневую границу вместо рассеянного света рефлектора.

Фары K5 различаются по рынку, поэтому рамок три: для китайских машин (CN, 2019–2022), для американских (USA, 2019–2022) и для европейских (EU, 2019–2024). Рынок обычно видно по номеру фары на наклейке корпуса и по форме отражателя; если сомневаетесь — пришлите фото фары, подскажем.

Рамки рассчитаны на Bi-LED модули с креплением Hella 3R. Для установки фару снимают и вскрывают, а после сборки на бутиловый герметик регулируют свет.

## volkswagen/transporter

Для Volkswagen Transporter T5 2002–2009 года есть два решения. Для фар со штатной линзой — рамки, которые меняют заводскую линзу на Bi-LED или ксеноновый модуль с креплением Hella 3R. Для рефлекторных фар, где линзы нет, — пластины, на которые линза ставится вместо отражателя ближнего света.

Определить свою фару просто: если за стеклом видна круглая линза — нужны рамки, если только зеркальный отражатель — пластины. Рамки и пластины подобраны на T5 до рестайлинга 2009 года.

Фару для установки снимают и вскрывают, линзу ставят на рамку или пластину, собирают фару на бутиловый герметик и регулируют свет.

Рамки рассчитаны на Bi-LED и ксеноновые модули с креплением Hella 3R. Перед заказом проверьте, есть ли в вашей фаре линза и поворачивается ли она вслед за рулём.

## porsche/cayenne

Переходные рамки для Porsche Cayenne подобраны на 955 и 958. Для Cayenne 955 2002–2007 — рамка под замену штатной линзы.

Для Cayenne 958 2010–2014 есть рамка для фар без адаптивного света и две рамки для фар с AFS Intellect. Для рестайлинга 2014–2018 — рамка для фар без AFS, металлическая рамка для фар с AFS и универсальная рамка для модулей Hella Intemo и VarioX с AFS.

Рамки рассчитаны на Bi-LED и ксеноновые модули с креплением Hella 3R. Перед заказом сверьте поколение, год выпуска и тип фары — с AFS или без.
